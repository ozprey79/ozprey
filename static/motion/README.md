# Motion source

Eadweard Muybridge, Animal Locomotion, plate 717 (1887), Cat trotting, changing to a gallop.
20 photographic exposures; public-domain historical work.

Source: https://commons.wikimedia.org/wiki/File:Cat_trotting,_changing_to_a_gallop.gif
Original: https://upload.wikimedia.org/wikipedia/commons/0/05/Cat_trotting%2C_changing_to_a_gallop.gif

cat-atlas.png contains the 20 exposures, arranged in five columns and four rows.
Each cell is 512 x 256 pixels. The shader applies the site's palette at runtime.
